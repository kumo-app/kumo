mihomo core bundled with Kumo

The program core/mihomo (core\mihomo.exe on Windows) is mihomo v1.19.32,
an unmodified official release binary of https://github.com/MetaCubeX/mihomo
("Clash.Meta"), licensed under the GNU General Public License v3.0 (see
LICENSE-mihomo.txt beside this file).

Source code of this exact version:
  https://github.com/MetaCubeX/mihomo/tree/v1.19.32
  https://github.com/MetaCubeX/mihomo/archive/refs/tags/v1.19.32.tar.gz

Kumo runs mihomo as a separate process and talks to it over its
external-controller HTTP API; Kumo's own code is not part of mihomo.
